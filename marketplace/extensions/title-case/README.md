# Title Case

The complete example from Lienzo's Help ("Make your own"): a tool that rewrites the titles of the selected cards in
Title Case, in one step you can undo. It asks for one permission, **Changes the canvas**.

It also offers one action to agents, `titleCase { ids? }`: the same code the button runs, so your agent can Title Case
cards for you. Its change shows in History as "Title Case (agent)".
